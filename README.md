## `03 / HOW I THINK`

```text
┌─ PRINCIPLES ───────────────────────────────────────────────────────┐
│                                                                    │
│  01  Constraint before cleverness                                  │
│      Memory, battery, network and privacy decide the architecture. │
│                                                                    │
│  02  The user never sees your architecture                         │
│      They feel speed, clarity and trust. Engineering serves that.  │
│                                                                    │
│  03  Own the whole path                                            │
│      Interface → logic → data → model → deployment.                │
│                                                                    │
│  04  A demo is not a product                                       │
│      Reliability, maintainability and documentation come next.     │
│                                                                    │
│  05  Private by default                                            │
│      If it can run on the device, it should.                       │
│                                                                    │
└────────────────────────────────────────────────────────────────────┘
```

### The thesis

> **AI should live where your data lives — on your device.**
> Faster responses. Works without internet. Costs nothing to run. Your data never leaves your hands.

I focus on lightweight models, quantization and local inference, so useful AI does not depend on a remote server.
